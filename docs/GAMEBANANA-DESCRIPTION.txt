LONGSHOT / HOOKSHOT - 0.5.0 NOTICE
There has been a lot of feedback about Longshot problems since 0.4.0: crashes while loading a save or an area,
a rebuild that stopped near 90% with "Longshot is still running from this folder", DLSS disappearing after a
rebuild, and the app choosing a ReLink or Hookshot builder for a Longshot game. 0.5.0 is meant to fix all of them.
The module changed, so rebuild the game once with 0.5.0. If a crash remains, attach logs/longshot_log.txt and the
new file in bug-reports/.

Super Hero Boost is a gameplay and HUD module for the Ocarina of Time remake (update v131072).

WHAT YOU ARE DOWNLOADING
The file in the Files tab is SuperHeroBoost-0.5.0-presets.zip: the mod itself, with all 12 named profiles of the companion app ready to install in an emulator. Every profile includes the boots/mask quick select. It contains no executable. The configuration app is a separate download (see "Installation app" below); it is not in the Files tab.

NEW IN 0.5.0
- Longshot 0.4.0 crashes fixed: the module was built with -Oz, whose machine outliner moved the pointer guards into
  helpers that return with the condition flags; Longshot's recompiler does not keep them, so a null pointer reached
  the HUD (guest 0x38 / 0x80). The module is now built without the outliner. Rebuild the game once.
- DLSS and FSR are kept when rebuilding: the app reads the launcher's settings, points the builder at the DLSS SDK
  and passes --fsr when the game had it. If DLSS was on and the SDK is missing, it stops instead of removing DLSS.
- ReLink support, plus the right builder for each game (Longshot / Hookshot / ReLink) on Windows, Linux and macOS.
- The app closes a running copy of the game before and during the build instead of stopping near 90%.
- Manual shield: ZL follows the game's Targeting Type, hold L to guard while targeting, R3 cancels; while it is
  enabled, the L item slot is removed from buttonMapping.
- Button mapping follows Swap Jump Controls (the B item slot moves to X and the Jump label moves to B).
- Quick select: removed the debug clock text; the clock always shows the time.
- Backup and uninstall record every file the install and the rebuild touch and restore exactly that (including
  ReLink files); generated caches are deleted, not copied.
- 0.4.0 brought the three HUD layouts, the exact bottle icons and the enemy speed/duplication options; they remain.

Every feature in this mod is optional. The installation app sets up the module once, and each system below has its own on/off switch, so you can use only what you want — with everything off, the game plays like vanilla. The Recommended profile turns everything on; change any option and the profile switches to Custom. Options take effect when you press Install again: for emulators nothing is recompiled and no file is edited by hand. (Longshot is different; see the Longshot section.)

STAMINA (optional)
- Can be turned off completely: no costs, no ring, no locks.
- Four styles: Hardcore (every action costs), Combat only, Sprint only, or Advanced (choose which actions cost).
- Exhaustion and regeneration, with individual costs for rolling, jumping, attacking, shooting, sprinting and shield blocking.
- Stamina ring next to Link, drawn with the game's own textures, or an optional compact segmented bar at the bottom.

DIFFICULTY (optional)
- Enemy health and damage taken multipliers from x1 to x3 (x1 is vanilla).
- No heart drops: dropped hearts become green rupees. Installed as a separate optional file; if it is not available, the app installs everything else and shows a note.

MOVEMENT (optional)
- Configurable sprint speed (+25% by default).

HUD (optional, one switch per element)
- Always-visible rupee counter and clock (off / 12 h / 24 h) with the game's native plate look.
- Per-area counter for Gold Skulltulas and heart pieces, for example SKULL 3/8  COR 0/2. It reads the save's persistent key set, so the count survives leaving and re-entering an area.
- Three layouts: Wide (four plates), Simple (the four counters at the bottom, no background) and Minimal (rupees and time above the minimap, heart pieces next to the native Skulltula counter on the Minus map).

BUTTONS (optional)
- B, L, R and ZR item buttons on the HUD, assignable from the pause menu's Items tab with X / L / R / A.
- The buttons show the exact bottle content for potions, blue fire, fish, bug, fairy, milk, half milk, letter, Poe, Big Poe and empty bottles.
- Switch, PlayStation and Xbox button styles.
- Extended layout (B, L, R, ZR, X, Y, A and the sword) or simple layout (only the assignable buttons, with B centred).
- L as an item button or as the game's own item selector.
- Songbook autoplay: select a learned song in the native songbook (ZL) and Link plays it with its effect. Learned songs only, not the Scarecrow's Song.

QUICK SELECT
- Hold D-pad Down to switch between the Iron Boots and Hover Boots; hold D-pad Up to switch between the Lens of Truth and the mask you were wearing.
- Only items in your inventory are used, and the game's equipment is applied immediately.
- Included in every named profile and in every preset of this download.

WORLD CHANGES (optional, each with its own switch)
- The three Great Fairy magic rewards are reordered: Hyrule Castle (child) gives Nayru's Love, Death Mountain Crater gives the magic spin attack and Desert Colossus gives double magic.
- Farore's Wind warp points can be placed outdoors.
- Known bug: press up and down a couple of times before the teleport menu responds.

PROFILES (optional shortcuts)
- Recommended, Base, Hero Mode, Hero + Stamina, Hero Explorer, Super Hero, Ultra Hero, Survival, World changes and two beta combinations, plus a fully custom setup.

BETA (optional, experimental, off unless you turn them on)
- Enemy duplication (Option A): clones every eligible generic enemy placement and shares the original resources, so the extra enemies actually appear and behave. Bosses, minibosses and scripted enemies are excluded.
- Enemy speed: movement, animation playback and attack cadence are separate levels, each with eleven multipliers from x0.5 to x6 (plus off). Some enemies or attacks may not change or may desync.
- They install extra romfs files and can break puzzles, quests or performance. Back up your save and test one at a time.

REQUIREMENTS
- The game on update v131072.
- An emulator that loads mods from its user/load folder, or a Longshot installation.
- Back up your saves. On Windows the app closes a running game before installing and during a rebuild; save first.

EMULATOR - QUICK INSTALL (PRESETS ZIP)
1. Download SuperHeroBoost-0.5.0-presets.zip from the Files tab and extract it.
2. Open the folder of the profile you want (01 Recommended, 02 Base, 03 Hero Mode, ...).
3. Copy its 00-Super-Hero-Boost folder into user/load/0400486024DEC000 (merge it if that folder already exists).
4. Start the game.
Only one profile can be installed at a time: they all use the same folder name, so replace the previous one.

EMULATOR - CUSTOM SETTINGS (APP)
1. Download SuperHeroBoostConfig.exe from GitHub Releases:
   https://github.com/kuribox/OOT-SuperHeroBoostMod/releases
   It is also published in the Tools section of this game. The module is bundled inside the app: you do not need Python.
2. Save your progress. On Windows the app closes the game for you before installing / building.
3. On the game profile, choose a preset (Recommended turns everything on) or adjust each section by hand: Stamina, Difficulty, HUD, Modifications.
4. Choose your emulator folder: the one that contains "user" (the app also detects a custom load_directory).
5. Press Install. It creates 00-Super-Hero-Boost inside user/load/0400486024DEC000 and patches the configuration you selected.
6. Start the game.

LONGSHOT, HOOKSHOT AND RELINK (use the app)
The presets zip is for emulators only. Static recompilations ignore exefs mods by design, so the module has to be
built into the game. Use the installation app from GitHub Releases:
https://github.com/kuribox/OOT-SuperHeroBoostMod/releases

1. Download and run SuperHeroBoostConfig.exe (or the Linux / macOS build).
2. Select the Longshot, Hookshot or ReLink target. The app detects the .longshot_exefs / .hookshot_exefs /
   .relink_exefs and the builder of that game (LongshotBuilder / HookshotBuilder / ReLink); the builder path is
   optional and can be changed if it is not detected.
3. Point it at your game folder, choose the profile / options and press Rebuild game.
4. The first build takes 25-45 minutes. Later code changes are incremental (about 5 minutes); profile, HUD and romfs
   changes need no rebuild.
5. 0.5.0 keeps DLSS / FSR and closes a running copy of the game on Windows so the final swap is not blocked.
6. Uninstall restores the original bin/longshot.exe, image.bin and exefs/main (and the ReLink files).

0.5.0 fixes the Longshot crashes from 0.4.0. The module is baked into image.bin: rebuild once with 0.5.0.

IN GAME
- Item buttons: pause menu -> Items tab, highlight an item and press X to put it on B, L on L and R on R. The game's own ZR box still works with A.
- Songbook: pick a learned song in the native songbook (ZL) and Link plays it with its effect.
- HUD: rupees and clock stay visible; under them you get the Gold Skulltula and heart-piece counter of the current area.
- Stamina: the ring next to Link shows what is left; it refills when you stop.
- Quick select: hold D-pad Down for boots or Up for masks; release/tap normally keeps the game's behaviour.
- To remove the mod, press Uninstall in the app (or delete the 00-Super-Hero-Boost folder).

INSTALLATION APP
- Prebuilt apps for Windows, Linux (x86_64) and macOS (Apple Silicon); also GUI and command-line modes from source (Python 3.10+ with Tkinter).
- Profiles, per-section settings, install and uninstall.
- Quick select card: boots and mask switching from the D-pad.
- Translations: Spanish, English, Portuguese, French, German and Italian.
- From 0.2.1 the app checks GitHub Releases on startup and offers to download a newer version. On Windows it can replace itself and restart; if the folder is read-only, it shows where the new file was saved.
- The app saves your settings automatically, but changes only reach the game after pressing Install again.

COMPATIBILITY
- Emulators: tested and working on lichii and Fritchii.
- Longshot: supported and tested. 0.5.0 fixes the 0.4.0 crashes; rebuild the game once with it.
- Hookshot: expected to work, not tested yet (same builder and make_game.py --update).
- ReLink: supported (bin/relink-game, .relink_exefs, RELINK_* variables). Install/backup tested; the full build has not been verified on a real ReLink install yet.
- Real hardware: not tested.
